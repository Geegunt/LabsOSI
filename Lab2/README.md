В директории лабораторной две папки:

- `src/` — исходники на Си, Makefile и интеграционные проверки в `tests/`.
- `report/` — отчёт `lab2.pdf`, его исходник `lab2.tex`, рисунки и журналы в `assets/`.

Для сдачи: https://github.com/Geegunt/LabsOSI/tree/main/Lab2

## Сборка и запуск

Команды выполняются из `Lab2`. Нужны C-компилятор и Make.

```sh
make -C src
(cd src && ./parent)
```

Родитель запускает `./child`, поэтому рабочей директорией программы должна быть `src`.

Первой строкой вводится имя выходного файла, затем строки с числами:

```text
results.txt
100 2 5
7.5 2.5
0 2
```

Ввод завершается Ctrl+D. Результаты в файле: `10`, `3`, `0`. Файл создаётся дочерней программой; существующий файл очищается. Пробелы в имени файла поддерживаются.

## Обмен и вычисления

Родитель создаёт два неименованных канала, вызывает `fork`, перенаправляет stdin/stdout ребёнка через `dup2` и запускает отдельную программу `child` через `execl`.

По `pipe1` передаются строки с числами. Через `pipe2` возвращаются байты `R` (готов), `K` (записано), `Z` (нулевой делитель), `E` (ошибка). После каждой строки родитель ждёт ответ. Диагностика и PID выводятся в stderr.

Первое число типа `float` последовательно делится на остальные: `100 2 5` означает `(100 / 2) / 5`. Одно число сохраняется без деления. Нулевой числитель допустим. При делителе `0` или `-0.0` оба процесса завершаются с кодом 2; следующие команды не выполняются. Ранее записанные результаты сохраняются.

Пустая строка, некорректное число, NUL, `nan`, `inf`, выход преобразования за диапазон и неконечный результат приводят к завершению с кодом 1. Десятичный разделитель — точка; экспоненциальная запись поддерживается. Длина строки ограничена доступной памятью. Результат печатается с `FLT_DECIMAL_DIG` значащими цифрами.

Нормальное завершение по EOF — код 0. Родитель закрывает каналы и получает статус ребёнка через `waitpid`. Если ребёнок уничтожен извне во время ожидания ввода пользователя, родитель обнаружит обрыв при следующем обмене.

## Проверки

```sh
make -C src test
```

В Debian 12 aarch64 с GCC 12.2 прошли все 18 тестов, включая `/dev/full`. На macOS проходят 17, Linux-проверка `/dev/full` пропускается. Реальные журналы тестов, сведения о среде и две трассировки `strace` находятся в `report/assets/linux/`.

Для повторения Linux-проверки через Docker Desktop:

```sh
sh src/tests/check_linux.sh
```

Для отдельной трассировки в Linux:

```sh
(cd src && strace -f -o ../report/trace.log ./parent)
```

В проверенной среде вызовы `pipe`, `fork`, `dup2`, `waitpid` отображаются как `pipe2`, `clone`, `dup3`, `wait4`.
